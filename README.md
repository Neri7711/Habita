# Habita / Arraigo

Agente asesor que recomienda dónde rentar o comprar en CDMX a personas que se reubican por trabajo,
explicando costo real, precio justo, confiabilidad del anuncio y encaje con la comunidad.

Contexto completo en `.kiro/steering/` y specs por fase en `.kiro/specs/`.

## Correr
```bash
uv sync
uv run pytest
```
